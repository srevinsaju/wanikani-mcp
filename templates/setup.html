wanikani-mcp

An unofficial MCP server for your WaniKani data. Not affiliated with WaniKani or Tofugu.

Use the hosted server

Add a connector with this URL. Your app asks you to sign in with a WaniKani API token.

{{ public_address }}/mcp

Or, in a client that reads a JSON config:

{
  "mcpServers": {
    "wanikani": {
      "type": "http",
      "url": "{{ public_address }}/mcp"
    }
  }
}

Run your own

Needs Docker and an API token from WaniKani settings.

{
  "mcpServers": {
    "wanikani": {
      "command": "docker",
      "args": [
        "run",
        "-i",
        "--rm",
        "ghcr.io/srevinsaju/wanikani-mcp:main",
        "--mode",
        "stdio",
        "--api-key",
        "YOUR_WANIKANI_API_KEY"
      ]
    }
  }
}
